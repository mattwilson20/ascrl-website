Operating limits
One active owner session; two-hour session expiry; 30-minute inactivity limit.
Private cloud artwork copies: 50 MB per project / 500 MB total pilot quota.
Host credential protected by Windows DPAPI, hash stored on the backend,
expires after 90 days. No service-role credential is present in the host/client.
Restrictive networks may require a TURN relay, which is not configured.
The private host's desktop shortcut must be started after reboot.
Keeping original model files off browsers is not an absolute anti-piracy
guarantee. Public use and model licensing remain outside this private pilot.

Supabase advisor notes
The private host credential table intentionally has RLS with no public policies
(default deny). The narrow security-definer host RPC is exposed to anon/auth
roles only because it independently authenticates the scoped 256-bit host token
on every call. These expected advisor findings were reviewed, not suppressed.
